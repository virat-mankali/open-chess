# OpenChess

Keep this repository a Bun-workspaces monorepo using Next.js App Router. Product apps belong in apps/, reusable domain logic in packages/. Do not place a second application at the repository root or create nested Git repositories. Do not introduce npm/pnpm/yarn lockfiles.

Web: apps/web. Shared chess domain: packages/chess-core. Future backend: apps/api (create only when implementing it). Root commands: bun install, bun run dev, bun run check.

Replica skills are installed in .agents/skills/replica-*. Their planning artifacts live in replica/. Engine binary assets are generated by scripts/prepare-engine.mjs and must not be committed. Maintain Stockfish attribution, license and exact source link in THIRD_PARTY_NOTICES.md.

Move quality must be computed from actual engine evaluations. Elo is approximate, not a certified rating. Never fabricate brilliant moves, accuracy or user statistics. Preserve PGN history for repetition rules and resume. Browser persistence must handle corrupt or unavailable localStorage.
